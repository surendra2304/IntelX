## Bugs I Found & Fixed
- **Delimiter Breakout Regex Word Boundary**:
  - *Bug*: `\b` word boundaries failed on symbols (`<<<END_...>>>`) because non-word angle brackets do not trigger word boundaries.
  - *Fix*: Replaced regex pattern with explicit symbol matching `<<<END_EXTERNAL_DOCUMENT>>>|<<<EXTERNAL_DOCUMENT`.
- **Closure Variable Binding in Regex Replacer**:
  - *Bug*: Inner replacement function captured loop variable `label` by reference rather than binding at definition.
  - *Fix*: Bound label as default keyword parameter in the replacement closure.
