## Bugs I Found & Fixed
- **Pydantic v2 Undefined Default Handling in Mock Generator**:
  - *Bug*: `field.default` in Pydantic v2 defaults to `PydanticUndefined`, causing validation errors during mock instantiation.
  - *Fix*: Checked `field.default is not PydanticUndefined` before assignment and recursively generated typed dummy values.
- **Markdown JSON Code Block Parsing**:
  - *Bug*: Raw LLM outputs enclosed in ````json ... ```` failed raw JSON decode.
  - *Fix*: Implemented automatic code fence stripping in `ModelGateway._try_parse_schema`.
