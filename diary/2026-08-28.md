## Bugs I Found & Fixed
- **Starlette TemplateResponse Argument Order**:
  - *Bug*: Calling `TemplateResponse("name.html", context)` caused Jinja2 cache lookup to fail with `TypeError: unhashable type: 'dict'`.
  - *Fix*: Refactored all route template invocations to use explicit keyword arguments (`request=request, name=..., context=...`).
- **Missing python-multipart Dependency**:
  - *Bug*: Form POST requests raised `RuntimeError: Form data requires python-multipart`.
  - *Fix*: Added `python-multipart` to `pyproject.toml` and environment dependencies.

## Key Decisions & Architecture
